# 对话区文件链接规范

文件引用统一使用 `WorkflowFileLink`；Markdown 与行内路径通过
`WorkflowMarkdownLink` 解析目标后复用它，读取文件行直接传入实际路径。

- **默认名称**：未提供标签、标签为空或标签等于原始链接/完整目标路径时，
  只显示文件名。Unix 与 Windows 路径使用相同规则。
- **自定义名称**：保留标签文字及格式，例如 `ui/index.ts`、`主题定义`。
  目录层级由标签指定，不固定截取两层，也不自动补目录消除重名。
- **行号**：使用 `文件名:行号`；自定义标签同样补充行号。
  标签已有相同的 `:行号`、`#L行号` 或 `(line 行号)` 时不重复追加。
- **悬浮**：使用公共 `Tooltip` 展示完整目标路径及行号，不使用原生 `title`。
  悬停 350ms 后显示，键盘聚焦立即显示；长路径换行，提示自动避让视口边缘。
- **打开**：在当前会话的右侧辅助区激活“文件”页，正文与目录树同时显示。
  始终使用实际路径读取文件并定位行号；缩短名称不改变目标，
  不对已经解析的文件路径再次解码。缺少工作目录的相对路径保留为不可点击文字。
- **复用**：调用方只提供路径、行号和可选标签，不自行截取目录或拼接行号。
  链接里的行内代码仅负责文字格式，不再嵌套文件链接或复制按钮。

规则参考本机 Codex 26.901.51231 的文件引用展示行为；本项目沿用简洁的 `:行号` 格式。
示例位于对话区“组件展示 → 公共展示组件 → 文件链接”。
