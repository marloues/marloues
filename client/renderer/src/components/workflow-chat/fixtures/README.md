# 对话区组件预览

启动桌面开发环境后，访问 renderer 的开发地址并添加：

`?workflowFixture=details&fixtureSection=components`

也可以在仓库根目录运行 `npm run test:conversation:preview`，然后打开
<http://127.0.0.1:5191/?workflowFixture=details&fixtureSection=components>。
这些入口仅在开发环境启用。

- **组件展示**：公共 UI 原语、消息与执行过程、轮次状态与耗时；直接引用正式组件。
- **内容**：Markdown、表格、代码、公式、Mermaid、媒体及流式交互。
- **工具结果**：MCP 内容、资源、图片结果卡及图片预览。
- **滚动 / 异常恢复**：历史加载、吸底与正文错误边界。

顶部可切换深色、浅色、暖色。主题与主分类写入当前 URL，刷新后保留；
不写入应用主题偏好。轮次示例中的运行时钟会递增，正文生成阶段会冻结处理耗时；
历史记录分别演示 73 秒、4 秒及未知耗时。切换轮次示例可重新开始演示。

工具只展示示例数据，不执行命令。轮次的复制操作使用剪贴板，分支操作仅记录演示次数。

“消息与执行过程”包含单文件、多文件、指定行及读取命令示例；点击路径打开示例文件，
读取行不显示“已读取”或详情入口，也不展开下级内容。可添加 `&fixtureGroup=activities` 直接进入这一组。
这些文件由展示页提供，正式会话仍通过桌面文件接口读取实际文件。

任务计划和审批状态记录不显示在对话活动列表中，也不计入活动步骤数；展示页遵循同一规则。
执行步骤由 `ComposerTaskProgress` 展示，权限审批使用交互区；需要用户回答的问题卡片仍保留。

“公共展示组件”的文件链接示例覆盖默认文件名、自定义目录层级、行号与格式化标签，
并提供两个不同目录下的 `index.ts`，用于检查名称与实际打开路径的对应关系。
统一规则见 [文件链接规范](../content/README.md)。

文件链接和审核按钮都接入正式辅助区：审核按钮常驻，右侧“审核”页汇总当前
会话的全部文件变更，目录树可筛选和切换文件；同一文件按时间展示多次修改。
审核卡默认使用透明底色，悬停时使用轻微凸起色。差异预览相对卡片或文件行
水平居中，根据可用空间上下翻转，并避开输入区及视口边缘；移入预览后可滚动
查看差异，Escape 或点击审核会关闭悬停预览。
预览目标宽 800px，上限为审核卡（或文件行）及窗口可用宽度；当前会话的辅助区只要展开就不显示
悬停预览，包括文件、审核、其他标签及空视图选择页，收起辅助区后恢复。
展示数据包含两个轮次、三个文件及对同一文件的两次修改。文件页同时保留正文
和工作区目录树，支持行号定位。右下角可以手动打开或收起辅助区。
审核和文件页共用可拖动分割线：向左拖保留正文至少 160px，向右拖到目录树
最小宽度 156px 后，再拖动超过 40px 收起目录树；顶部文件夹按钮恢复目录树。
分割线支持方向键调整、Enter 收起和 Escape 取消当前拖动，不关闭辅助区标签。
关闭最后一个标签时自动收起辅助区；手动重新打开后可以停留在空视图选择页。
关闭后不会重放已处理的打开请求，后台浏览器通知也不会重新展开；点击文件、
审核或子任务入口属于主动打开操作。

“消息导航”页（`fixtureSection=navigation`）使用正式虚拟列表和滚动逻辑，
演示长会话的左侧短横线导航。导航仅在消息正文左侧已有留白至少 72px 时显示，
不挤压正文；打开辅助区或缩窄对话区后会自动隐藏。悬浮/键盘聚焦显示问题与
回复摘要，点击/Enter 跳转，方向键切换，Escape 关闭预览。跳转历史后暂停跟随
最新输出；顶部提供宽窄切换、追加回复和会话切换的验收控件。

导航整列最高 240px，短线间距 10px；默认显示等长短线，仅用颜色标记当前阅读位置。悬浮或键盘聚焦时，当前
操作的短线与相邻短线按距离逐渐伸长，形成波浪；移开后恢复等长短线。
