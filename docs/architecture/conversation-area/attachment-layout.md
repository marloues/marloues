## Marloues 的实际修复

- 将图片和引用组改为“滚动视口 + 正向内容轨道”，修复直接对条目使用反向 flex 导致的顺序颠倒。
- `WorkflowMarkdownLink` 允许组合控件提供样式；整个文件标签作为一个按钮，修复嵌套 inline 文本样式导致图标换行和文字重叠。
- 普通文件只显示一次名称，有行号时单独显示；长名称通过完整文字及 title 保留，视觉宽度受限。
- 使用相邻 `UserMessage.module.css` 和原有主题变量，隐藏可视滚动条，保留横向滚动和可见键盘焦点。
- Tab 焦点到达部分裁切的附件时，将整个控件滚入视野；排除文件预览 portal 的焦点，防止误滚动。
