# 恢复任务、历史与滚动

## 重新打开任务

来源：[E37](evidence.md#e37)、[E38](evidence.md#e38)、[E39](evidence.md#e39)。

| 编号 | 条件 | 客户端处理及显示含义 |
|---|---|---|
| H01 | 需要恢复任务 | 使用 `needs_resume → resuming → resumed` 一类独立恢复状态，结合 stream role 和 runtime status；轮次仍在执行与本窗口已接上连接不是一回事。 |
| H02 | 异步恢复期间任务上下文发生变化 | 多个 await 后检查本次 resume attempt 是否仍有效；失效则退出，防止旧恢复结果覆盖后来状态。 |
| H03 | 窗口不能取得任务执行流 | 特定 inactive hotkey window 路径跳过抢占连接，返回 not-ready；已有 follower 可走已有 owner 的状态。 |
| H04 | 执行恢复准备 | 读取任务元数据、工作目录/可写路径、最新设置与权限，再发 `thread/resume`；并非重新发送上一条用户消息。 |
| H05 | 启用 tail hydration 等相应分支 | 先载入最近历史，若干分支初始取 5 轮；恢复期间缓冲通知，接入快照后释放。这里的 5 不应推广成所有路径的固定页大小。 |
| H06 | 仍有历史且策略允许继续加载 | 条件满足时后台加载剩余记录；goal 的后台恢复还检查期间状态是否已被修改，避免旧查询覆盖新目标。 |
| H07 | 恢复失败 | 当前有效尝试撤销自己取得的 owner、释放通知缓冲并退回 needs_resume；特定 writer 冲突仍可尝试读取历史；错误后仍可能看见历史，但不代表有权继续执行。 |
| H08 | 同时请求加载同一任务历史 | 合并正在进行的加载 Promise；需要全量时可在已有局部加载后继续；防止滚动、搜索和重新打开同时重复拉取。 |
| H09 | 加载较早记录 | 某些路径优先补齐部分轮次的 items，再取更早 turns；canonical history 另按历史边界合并；“还有历史”可能指上一轮，也可能指这一轮较早的过程条目。 |
| H10 | 分页响应返回 | 检查 cursor、来源或 canonical 边界是否仍有效；stale 响应不直接应用；失败保留 cursor 并重置加载标记；历史必须可重试，也不能因为晚到响应重复或错排。 |
| H11 | 重建可见轮次 | 使用稳定 turnKey/history key，复用满足相等条件的已有 entry；占位条目含预计高度；展示层不必每次把整段历史全部当成新组件。复用规则本身不证明页面完全无跳动。 |

## 滚动与阅读位置

来源：[E40](evidence.md#e40)、[E41](evidence.md#e41)、[E45](evidence.md#e45)。

该组件区分底部/顶部原点，部分布局使用反向 flex。以下阈值使用组件自己的“离底部距离”换算，不能直接拿原生 scrollTop 代入所有情形。

| 编号 | 条件 | 处理与视觉效果 |
|---|---|---|
| H12 | 离底部不超过 24 CSS px | 视为接近底部；滚动跟随及返回底部按钮使用这一类判断；存在容差，不能要求精确等于 0。 |
| H13 | 回答增长或容器尺寸改变 | ResizeObserver 和保存的距离参与调整；阅读旧内容时补偿内容增长，贴底时考虑 response spacer；新输出与用户阅读位置需要协调，而非每个 token 都调用 scrollIntoView。 |
| H14 | 判断返回底部按钮是否出现 | 有 response spacer 时与 spacer 高度加 24 比较，否则看 controller 的 scrolled-from-bottom；运行提示点还要求按钮可见；不只是“scrollTop 不为零就显示”。 |
| H15 | wheel、触摸、键盘或指针输入 | 记录用户滚动意图，区别于布局引起的滚动；意图跟踪有 1000 ms 时效，触摸移动阈值为 8 px；程序滚动不能被误当作用户主动离开底部。 |
| H16 | 键盘用于阅读滚动 | ArrowUp/Home/PageUp 为 away，ArrowDown/End/PageDown 为 toward；Space 依 Shift 决定方向；已处理事件、repeat、输入控件/可编辑区，以及按钮上的空格有排除条件；光标在输入框时按方向键，不应错误改变阅读跟随模式。此处是滚动意图识别，不是聊天输入框发送快捷键。 |
| H17 | wheel 使用不同 deltaMode | 行单位乘 16，页单位乘视口高度，像素单位保留原值；不同设备和滚动事件需要统一单位。 |
| H18 | 接近历史顶部 | 普通加载阈值 64 px；允许跨隐藏历史页时阈值可取视口高度与 64 的较大值；在用户真正撞到顶部前即可开始获取旧内容；是否加载还受分页状态约束。 |
| H19 | 程序滚回底部 | 本组件的动画时间常量为 260 ms；这只是一个组件常量，不表示整个 App 所有滚动统一采用该速度。 |

上表静态确认了滚动控制意图。实际长文本、图片尺寸迟到、折叠高度变化、字体加载和触控板惯性叠加后的效果仍需真实浏览器/UI 回放验证。
